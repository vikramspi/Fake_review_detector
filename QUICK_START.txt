## 📊 WHAT THE MODEL ANALYZES

The detector examines 9 key features:

| Feature | Purpose | CG Typical | OR Typical |
|---------|---------|-----------|-----------|
| **Text Length** | Review size | 200-400 | 300-500 |
| **Vocabulary Richness** | Word variety | 0.72 | 0.78 |
| **Avg Word Length** | Word complexity | 4.8 | 5.1 |
| **Sentence Count** | Structure | 3-4 | 4-5 |
| **Punctuation Ratio** | Punctuation density | 0.08 | 0.09 |
| **Uppercase Ratio** | Capitalization | 0.05 | 0.06 |
| **Special Chars** | Symbol usage | 0.02 | 0.03 |
| **Repetition Score** | Word repetition | 0.25 | 0.15 |
| **Sentence Length** | Complexity | 8.5 | 11.2 |

## 🔧 ADVANCED CUSTOMIZATION

### **Adjust Detection Sensitivity**
Edit `config.py`:
```python
RISK_THRESHOLDS = {
    'min_text_length': 100,      # Change to 80 for lower sensitivity
    'min_vocab_richness': 0.70,  # Change to 0.65 for lower sensitivity
    # ... other thresholds
}
```

### **Modify Model Parameters**
Edit `config.py`:
```python
MODEL_CONFIG = {
    'n_estimators': 100,         # Increase to 200 for better accuracy
    'max_depth': 15,             # Adjust tree depth
    'min_samples_split': 10,     # Control overfitting
}
```

### **Retrain with New Data**
Replace CSV file:
```bash
# Replace Final_enhanced_dataset (1).csv with your CSV
# Delete fake_review_model.pkl
# Run app again - it will retrain automatically
```

## 🎓 KEY INSIGHTS FROM TRAINING DATA

### **AI-Generated Reviews Typically:**
- ✗ Shorter (200-400 chars vs 300-500)
- ✗ More repetitive (lower vocabulary richness)
- ✗ Simpler structure (fewer sentences)
- ✗ More formal/generic patterns
- ✗ Less specific details

### **Genuine Reviews Typically:**
- ✓ Longer and more detailed
- ✓ Higher vocabulary diversity
- ✓ More sentences with varied structure
- ✓ Include specific product details
- ✓ Mix of positive and negative points

## 🛠️ TROUBLESHOOTING

### **"Port already in use"**
```bash
streamlit run fake_review_detector.py --server.port 8503
```

### **"Module not found"**
```bash
pip install -r requirements.txt --upgrade
```

### **"CSV file not found"**
- Ensure `Final_enhanced_dataset (1).csv` is in the same directory
- Check file name matches exactly (including spaces)

### **Slow first prediction**
- First prediction trains the model
- Subsequent predictions are fast (<100ms)
- Model is cached after training

### **Model not retraining**
- Delete `fake_review_model.pkl` file
- Run app again to retrain
